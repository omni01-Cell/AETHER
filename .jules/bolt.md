## 2026-08-17 - [Pre-calculating Invariants and Eliding Math in Rust DSP Loops]
**Learning:** Inner loop DSP math (running 44,100+ times per second per channel) is a massive bottleneck if invariant variables are repeatedly calculated. Furthermore, direct slice indexing within such loops forces Rust to inject runtime bounds checks. Converting linear paths to decibel space (`log10`, `powf`) unconditionally for dynamic compression destroys performance when the sample is under the threshold anyway.
**Action:** When optimizing Rust DSP loops, extract invariants (e.g. `10.0f32.powf(...)`) before the loop. Use `iter_mut().zip()` to iterate through parallel mutable slices concurrently, removing direct indexing and eliding runtime bounds checks. Finally, calculate the linear threshold outside the loop and use an `if *env > threshold_linear` guard to completely elide decibel space conversion overhead for uncompressed samples.
