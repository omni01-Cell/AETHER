## 2026-07-05 - Keyframe search binary search\n**Learning:** In highly queried structures like KeyframeTrack where interpolations happens frequently, standard linear scanning over timeframes O(N) is an anti-pattern. Rust arrays can leverage `partition_point()` to achieve O(log N) searches natively for sorted arrays.\n**Action:** Whenever interpolating over sequences indexed by a monotonically increasing property (like timestamps), immediately reach for a binary search equivalent (like `partition_point`).
